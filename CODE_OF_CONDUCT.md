# Code of conduct

WireHub follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good faith, and keep
discussion about the work. Harassment, personal attacks, discriminatory
language and publishing others' private information are not acceptable,
in the repository or in any space connected to the project.

**Reporting.** Contact the maintainers privately — through a private
security advisory on GitHub (Security → Report a vulnerability) marked
"conduct", or by the contact on the maintainer's GitHub profile. Reports are
handled confidentially. Maintainers may remove content, and warn, suspend or
ban participants, following the Covenant's enforcement guidelines.
