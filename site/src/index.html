Config generator

A compose.yaml and an optional .env for a self-hosted WireHub, for a terminal or for a Docker UI (Portainer, Komodo, Dockhand …): paste both, deploy, open the URL and finish /setup.

Everything happens in this browser

This page runs entirely in this browser session. Nothing you type is sent anywhere: the page makes no network request at all (its content security policy forbids it), has no analytics and stores nothing. Secrets, if you ask for them here, come from your browser's own random generator (WebCrypto). You can save this page and use it offline.

The same result without this page

You do not need the generator. With no .env at all, the stack generates every secret itself on first start:

mkdir wirehub && cd wirehub
curl -fsSLO https://raw.githubusercontent.com/formless63/wirehub/main/compose.yaml
docker compose up -d
docker compose logs wirehub      # the first-run setup code

For optional settings, download .env.example beside it, copy it to .env and uncomment what you need. To keep every secret in that file instead (a password manager, a re-deploy onto fresh volumes), the terminal script fills them in:

curl -fsSLO https://raw.githubusercontent.com/formless63/wirehub/main/.env.example
curl -fsSLO https://raw.githubusercontent.com/formless63/wirehub/main/scripts/setup-env.sh
bash setup-env.sh

Sign-in and everything else

Sign-in is on: first-run setup makes your account, and you invite everyone else. GitHub, Google, single sign-on (OIDC), magic links over SMTP, allowed emails, alerts to a webhook, the git mirror and the job settings are set later in the app, under Settings; they apply at once, with no redeploy. Only what the install needs is set here.
